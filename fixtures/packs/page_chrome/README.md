# Page chrome smoke packs (THI-392)

Native PDF header/footer knobs. Tokens: `{page}`, `{pages}`, `{title}`.
Regenerated by `cargo run --example gen_sample_fixtures`.

| Pack | Shows |
| --- | --- |
| `page_chrome` | all knobs; footer `{page} / {pages}` center; header `{title}` left |
| `page_chrome_footer_left` | footer `align = left` |
| `page_chrome_footer_center` | footer `align = center` |
| `page_chrome_footer_right` | footer `align = right` |
| `page_chrome_fmt_slash` | footer `format = "{page} / {pages}"` |
| `page_chrome_fmt_of` | footer `format = "Page {page} of {pages}"` |
| `page_chrome_fmt_bare` | footer `format = "{page}"` |
| `page_chrome_fmt_title_page` | footer `format = "{title} — {page}"` |
| `page_chrome_header_center` | header `align = center` |
| `page_chrome_header_right` | header `align = right` |

Smoke PDFs: `tmp/thi-392-smoke/<doc>__<pack>.pdf` (`manuscript_chapters / field_notes / studio_brief`).

```bash
mkdir -p tmp/thi-392-smoke
for doc in manuscript_chapters / field_notes / studio_brief; do
  for pack in page_chrome page_chrome_footer_left page_chrome_footer_center page_chrome_footer_right page_chrome_fmt_slash page_chrome_fmt_of page_chrome_fmt_bare page_chrome_fmt_title_page page_chrome_header_center page_chrome_header_right; do
    cargo run -q --bin tes -- export "fixtures/samples/${doc}.tes" \
      --pdf --backend native \
      --template-root fixtures/packs --template "$pack" \
      -o "tmp/thi-392-smoke/${doc}__${pack}.pdf"
  done
done
```
